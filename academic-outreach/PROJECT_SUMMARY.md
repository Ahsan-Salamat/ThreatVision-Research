# Project summary

ThreatVision began as a Software Engineering final year project at The University of Faisalabad. Ahsan Ali Salamat independently implemented the technical system. The university records the project as a group submission with Usman Manzoor. The prototype combines static Windows Portable Executable analysis with a byte-bigram representation transformed by the discrete cosine transform and scored by a MobileNetV2 model. Static criteria determine the final label, while the neural output can adjust the numerical threat score by up to five points. A post-submission diagnostic pilot observed different neural responses to overlays across two source files. It lacked an independently labeled malicious cohort and cannot establish detection performance. The research question is whether the representation adds classification information beyond simple file statistics and static PE features on held-out data. The research repository documents the implementation, pilot limitations, and proposed evaluation. A read-only interface walkthrough is prepared locally, with live inference and uploads disabled.
